# Brawl Competitive

Plataforma Android de análisis competitivo para Brawl Stars.

## Objetivo
Una aplicación centrada exclusivamente en competitivo: meta por mapa y modo, estadísticas, counters, builds, draft y seguimiento de jugadores.

## Arquitectura
- `android/`: cliente Android nativo (Kotlin + Jetpack Compose).
- `backend/`: API y motor de datos (Python + FastAPI).
- `.github/workflows/`: automatizaciones.

## Estado
Bootstrap inicial del proyecto. Las estadísticas deben indicar siempre su fuente, fecha de actualización y tamaño de muestra.

> Proyecto independiente y no afiliado oficialmente a Supercell.
