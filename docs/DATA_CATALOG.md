# Catálogo visual de datos

## Brawlers
GET /catalog/brawlers

Incluye nombre e imagen, además de gadgets y habilidades estelares con nombre, descripción e imagen.

## Mapas
GET /catalog/maps

Incluye nombre e imagen del mapa y el modo con nombre e icono.

## Regla
La interfaz debe mostrar **imagen + nombre**.

Pendiente: refuerzos, hipercargas, rangos y otras mecánicas visuales.
