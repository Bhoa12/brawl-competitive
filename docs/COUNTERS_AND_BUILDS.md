# Counters y builds

El endpoint de recomendaciones está separado de las estadísticas brutas.

Cada counter final debe estar asociado a:
- brawler objetivo;
- brawler que realiza el counter;
- puntuación o evidencia;
- gadget exacto;
- estelar exacta;
- refuerzos exactos;
- contexto competitivo;
- parche.

El servicio devuelve una lista vacía cuando todavía no existen datos validados. Nunca debe presentar recomendaciones inventadas como datos reales.
