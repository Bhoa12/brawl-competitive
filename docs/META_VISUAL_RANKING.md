# Ranking visual del meta

Los resultados de analytics se convierten en tarjetas competitivas.

Cada tarjeta contiene:
- posición;
- imagen;
- nombre;
- pick rate;
- win rate;
- picks y victorias.

La capa de catálogo resuelve IDs a recursos visuales. El catálogo inicial es una semilla de desarrollo y debe sincronizarse automáticamente con el catálogo completo del backend antes de producción.
